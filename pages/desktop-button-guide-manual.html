바탕화면에 온라인교무실 바로가기 버튼 만들기

원본 Canva 슬라이드 열기

Google 사이트를 바탕화면 앱 버튼으로 설치하는 절차

준비·주의

  • Chrome에서 온라인교무실 페이지를 먼저 엽니다.
  • 설치 후 바탕화면에 온라인교무실 버튼이 생성됩니다.
페이지 열기앱으로 설치이름 지정완료 확인
1

온라인교무실 페이지 열기

  • 바탕화면 버튼으로 만들 온라인교무실 페이지를 Chrome에서 엽니다.
2

페이지를 앱으로 설치

  • 우측 상단 메뉴를 클릭합니다.
  • 전송, 저장, 공유를 선택합니다.
  • 페이지를 앱으로 설치를 클릭합니다.
3

이름을 지정하고 설치

  • 버튼 이름을 확인하거나 원하는 이름으로 변경합니다.
  • 설치를 클릭합니다.
4

바탕화면 버튼 확인

  • 바탕화면에 온라인교무실 버튼이 생성되었는지 확인합니다.

완료 확인

  • 페이지를 앱으로 설치
  • 버튼 이름 확인
  • 설치 완료
  • 바탕화면 버튼 생성
원본 Canva 자료를 바탕으로 재구성한 매뉴얼입니다. 이미지가 있는 단계는 우측 상단 🔍 버튼으로 원본 장면을 크게 볼 수 있습니다.
