북마크 수정하기 (관리 북마크)

원본 매뉴얼 페이지 열기

Google 관리 콘솔에서 학교 공통 및 교과별 관리 북마크 폴더에 사이트를 추가·수정하는 방법입니다.

필수 확인
  • admin.google.com 접속은 *@hongik68.sen.hs.kr로 로그인하셔야 합니다(안 될 경우 Edge 브라우저에서 실행).
  • 최상단 학교 공통 사이트 추가·수정은 관리자와 협의 후 진행해 주세요.
1. Chrome 설정에서 조직 선택 후 '북마크' 검색 2. [관리 북마크]의 교과별 폴더에 사이트 추가
1

admin.google.com > [기기 > Chrome > 설정]에서 조직 단위를 먼저 선택하고 "북마크"를 검색합니다.

  • 좌측 메뉴 [기기 → Chrome → 설정]으로 이동한 뒤, 가운데 조직 단위에서 홍대부여고를 먼저 선택합니다.
  • 상단 [사용자 및 브라우저 설정] 탭의 필터 검색창에 북마크를 입력해 검색한 후, 하단 사용자 환경의 [관리 북마크]를 클릭합니다.
2

선택한 조직 단위를 확인하고 [교과별 폴더] 내 해당 교과 폴더에 사이트를 추가합니다.

  • 좌측에서 선택한 조직 단위(홍대부여고)가 맞는지 다시 확인합니다.
  • [관리 북마크 > 교과별 폴더] 하위의 해당 교과 폴더(국어, 영어, 수학, 사회, 과학, 예체능 등)에 추가를 원하는 사이트를 등록하고 우측 상단 [저장]을 누릅니다.
💡 상단의 학교 공통 사이트(디벗-홈페이지, 홍대부여고-홈페이지, 리로스쿨 등)는 관리자와 협의 후 추가해 주세요.
