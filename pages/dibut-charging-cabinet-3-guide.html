디벗 충전함 사용법 (3학년 - 등대씨엔씨 도어락)

원본 매뉴얼 페이지 열기

3학년 교실 디벗 충전보관함(등대씨엔씨) 도어락 비밀번호·디지털 카드 설정 및 방전·분실 시 대처 방법입니다.

핵심 요약
  • 도어락 초기 비밀번호: 1111 + [OK]  |  관리자 비밀번호: 8810 (또는 초기 9079 / 1234, 관리자 4321)
  • 등대씨엔씨(Deungdae C&C) 고객센터: 1588-1859
1. 도어락 열기 (1111 + OK) 2. 비밀번호 변경 3. 디지털 카드(관리자·사용자) 등록 4. 방전 시 비상급전 · 분실 · 초기화
1

[도어락 여는 법] 비밀번호 입력 후 [OK] 버튼을 누릅니다.

  • 도어락 초기 비밀번호: 1111 / 관리자 비밀번호: 8810
  • 도어 오픈 방법: 비밀번호 + [OK] (예: 1111 + [OK])
  • 도어 잠금: 도어를 닫으면 자동으로 잠깁니다.
2

[비밀번호 변경 방법] 현재 비번 + [C] 입력 후 새 비번(4자리) + [OK]를 누릅니다.

  • ① 현재 비밀번호 + [C]를 누르면 부저가 울리고 녹색 표시등이 깜빡거립니다.
  • ② 새로운 비밀번호(4자리) + [OK]를 누르면 긴 부저가 울리고 변경됩니다(관리자 비밀번호 변경도 동일).
⚠️ 비밀번호를 4번 틀리면 1분간 작동하지 않습니다.
3

[디지털 카드 등록 방법] 관리자 카드를 먼저 등록한 뒤 사용자 카드를 추가합니다.

  • [관리자 카드] 먼저 등록 (도어 오픈 및 추가카드 등록 시 필요):
    ① 관리자 비밀번호 + [C] 입력 (긴 부저가 울리고 녹색 표시등이 깜빡거림)
    ② 카드를 전면에 접촉하고 [C]를 누르면 등록됩니다.
  • [사용자 카드 등록] (도어 오픈용, 최대 10장):
    ① 등록된 관리자 카드를 전면에 3초간 접촉 (긴 부저가 울리고 녹색 표시등이 깜빡거림)
    ② 추가할 카드를 접촉 후 [C]를 누르면 등록됩니다.
4

[관리 및 주의사항] 방전 시 대처, 비밀번호 분실, 도어락 초기화 및 무음 모드

  • 🔋 도어락 방전 시 대처방법: 부저가 3번 울리고 빨간 표시등이 켜지면 배터리 교체 시기입니다.
    ① 도어락 전면 C-type 포트에 저전력 보조배터리(또는 A to C 케이블)를 연결해 비상전원 임시 공급
    ② 비밀번호 입력 후 도어 오픈 → ③ 도어락 뒷면 덮개를 열어 AAA형 건전지 3개를 교체합니다.
  • 🔑 비밀번호 분실 시: 관리자 비밀번호 + [OK] (예: 8810 + [OK] 또는 4321 + [OK]) 입력 시 초기 비밀번호로 변경됩니다.
  • 🔄 도어락 초기화 방법 (디지털카드 해제 시 필요): 도어락 뒷면 덮개를 열어 RST 버튼(초기화 버튼)을 꾹 누르면 삐 소리와 함께 비밀번호와 디지털카드가 모두 초기화됩니다.
  • 🔇 무음 모드 켜기/끄기: [OK] 버튼을 3초간 누르면 설정됩니다.
