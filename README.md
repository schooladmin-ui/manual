## 📖 프로젝트 개요

본 프로젝트는 홍익여자고등학교 교원의 원활한 디지털 교무 업무를 지원하기 위해 제작된 종합 매뉴얼 포털입니다.  
Chrome 브라우저 초기 설정부터 온라인교무실 접속 및 바로가기 앱 설치, Google Sites 편집, Google NotebookLM AI 활용, 공유 폴더 보안 권한 설정, 연수서명부 날인, Google Chat 채팅방(스페이스) 생성, Google Groups 그룹 만들기까지 **총 9개 매뉴얼(39단계 실무 가이드)**을 체계적으로 묶어 제공합니다.

## ✨ 주요 기능

### 1. 직관적인 `n × 5` 버튼 레이아웃 및 쾌적한 스크롤 뷰
- 상단에 **'온라인 교무실 매뉴얼'** 메인 타이틀과 함께 매뉴얼 선택 버튼이 **`n × 5` 그리드(`repeat(5, 1fr)`)** 형태로 깔끔하게 배치됩니다.
- 버튼을 클릭하면 페이지 새로고침 없이 하단에 해당 매뉴얼 본문이 즉시 표시되며, 아래로 스크롤할 때 매뉴얼 선택 패널이 화면을 가리지 않도록 자연스럽게 함께 스크롤됩니다.

### 2. 세부단계별 고화질 스크린샷 돋보기(`🔍`) 모달 뷰어 & 인라인 이미지 지원
- 각 매뉴얼의 세부 절차 단계마다 우측 상단 돋보기(`🔍`) 버튼을 클릭하면 고화질 원본 스크린샷이 모달 팝업으로 즉시 확대 표시됩니다 (`ESC` 키 또는 배경 클릭으로 닫기).
- **[그룹 만들기](pages/google-groups-create-guide.html)** 매뉴얼처럼 한눈에 확인이 필요한 화면(`groups.google.com` 접속 및 `+ 그룹 만들기` 위치)은 버튼 클릭 없이 본문 안에 바로 표시(`.inline-figure`)됩니다.

### 3. 구글 채팅방(스페이스) 및 그룹 만들기 연동 구성
- **[구글 채팅방(스페이스) 생성](pages/google-chat-space-guide.html)** 매뉴얼은 1단계만 **학생(`학교계정_학생`) / 교사(`학교계정_교사`) 2열 레이아웃**으로 구분하고, 2~4단계는 공통 절차로 통합하여 가독성을 높였습니다.
- 1단계 하단에는 **[그룹 만들기](pages/google-groups-create-guide.html)** 매뉴얼로 즉시 이동하는 공통 안내 배너(`.group-link-panel`)가 배치되어 있습니다.
- 2단계 우측에는 **`'새 채팅'과 '새 스페이스'의 차이점`** 비교 안내 박스(클릭 시 비교 스크린샷 모달 표시)를, 3단계 우측에는 계정 구분 초대 안내 박스를 동일한 강조 스타일(`#fffbeb` 노란색 배경)로 나란히 배치했습니다.

### 4. 각 매뉴얼 및 모달 내 원본 Canva 슬라이드 / 독립창 열기 바로가기
- 각 매뉴얼 상단 우측에 **[원본 Canva 슬라이드 열기]**(Canva 원본이 있는 매뉴얼) 및 **[독립창 열기]**(`pages/*.html` 새 탭 열기) 버튼이 제공됩니다.

### 5. URL 해시 라우팅 및 인쇄 지원
- 브라우저 주소창에 `#google-chat`, `#google-groups`, `#notebooklm` 등 해시를 붙여 특정 매뉴얼로 직접 연결할 수 있습니다.
- 상단 **[인쇄하기]** 버튼 클릭 시 현재 선택된 매뉴얼만 인쇄용 규격 레이아웃으로 깔끔하게 출력됩니다.

## 🚀 배포 및 실행 방법

### 방법 1: GitHub Pages 호스팅 배포
- 연결된 GitHub 저장소: [`https://github.com/schooladmin-ui/manual`](https://github.com/schooladmin-ui/manual)
1. 변경 사항을 커밋 & 푸시합니다:
   ```bash
   git add .
   git commit -m "docs: 매뉴얼 업데이트 및 index.html 재빌드"
   git push origin main
   ```
2. GitHub 저장소의 **Settings → Pages**에서 `main` 브랜치 `/ (root)` 경로로 자동 배포됩니다.

### 방법 2: 온라인교무실(Google 사이트) 내 일체형 삽입
1. 배포된 웹사이트 주소를 복사합니다.
2. Google Sites 온라인교무실 편집 화면에서 **[삽입] → [임베드 (URL로 삽입)]**을 선택합니다.
3. 복사한 주소를 입력하고 [전체 페이지]로 배치하면 온라인교무실 화면 안에 가이드북 포털이 내장됩니다.

### 방법 3: 오프라인 로컬 실행
- 인터넷이 연결되지 않은 PC나 교내 공유 드라이브, USB에서도 `index.html` 또는 `pages/` 폴더 내 개별 HTML 파일을 더블클릭하면 즉시 열립니다.

## 🛠️ 매뉴얼 수정 및 재빌드 방법

`pages/` 폴더 내 개별 매뉴얼 HTML 파일(`pages/*.html`)을 수정하거나 새 매뉴얼을 추가한 경우 다음 명령어로 `index.html`을 최신 상태로 갱신할 수 있습니다:

```bash
# Python 3 실행
python bundle_manuals.py
```

- 스크립트 실행 즉시 `pages/` 폴더의 9개 매뉴얼 본문과 내장 이미지를 추출하여 `index.html`에 일괄 반영합니다.

## ⚠️ 유의 사항

1. **학교 계정 로그인 필수**:
   - 모든 온라인교무실, Google 드라이브, Google Chat 채팅방(스페이스), Google Groups(`groups.google.com`) 작업은 개인 일반 Gmail이 아닌 **학교 계정(`@hongik68.sen.hs.kr`)**으로 로그인해야 정상적인 권한 적용 및 구성원 초대가 가능합니다.

   - 포털 상단의 **[인쇄하기]** 버튼을 누르면 상단 네비게이션과 버튼이 자동으로 숨겨지고, 현재 선택된 매뉴얼 본문만 깔끔한 A4 규격 레이아웃으로 출력됩니다.
