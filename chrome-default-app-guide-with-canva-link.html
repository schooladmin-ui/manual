크롬브라우저 기본앱으로 설정하는 방법

원본 Canva 슬라이드 열기

Windows에서 웹 브라우저 기본 앱을 Google Chrome으로 지정하는 3단계 안내

주의

검색어는 반드시 ‘기본 앱’처럼 띄어쓰기까지 포함해 입력하세요. 메뉴 이름은 Windows 버전에 따라 조금 다를 수 있습니다.

1

Windows 설정 열기

화면 왼쪽 아래 Windows 시작 버튼을 누른 뒤 설정을 클릭합니다.

시작 버튼 → 설정
2

기본 앱 검색

설정 검색 창에 기본 앱을 입력하고 검색 결과의 기본 앱을 선택합니다.

‘기본 앱’ 입력 → ‘기본 앱’ 선택
3

Chrome 선택

화면 아래쪽의 웹 브라우저 항목을 클릭한 뒤 목록에서 Google Chrome을 선택합니다.

웹 브라우저 → Google Chrome
1

검색 결과가 안 보일 때

  • 검색어를 기본 앱으로 입력했는지 확인합니다.
  • ‘기본’과 ‘앱’ 사이에 띄어쓰기를 넣습니다.
2

Chrome 선택이 안 보일 때

  • 기본 앱 설정 화면을 아래로 스크롤해 웹 브라우저 항목을 찾습니다.
  • 목록에서 Google Chrome을 선택했는지 확인합니다.
